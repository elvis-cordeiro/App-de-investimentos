# DollarPath - Roteiro de Implementação

## Fases do Projeto
1. **Fundação**: Monorepo configurado, Vite + React + TypeScript + Tailwind CSS.
2. **Design System & Shell**: Dark premium theme (#090d12), navegação responsiva (Sidebar no desktop, BottomNav no mobile).
3. **Dashboard Interativo**: Resumo financeiro compacto, carrossel de oportunidades, feed de notícias editorial com separação fato/análise.
4. **Carteira & Transações**: Registro de ativos, aportes, cálculo automático de preço médio e alocação.
5. **Planejamento & Metas**: Gestão do aporte mensal de R$ 300, reserva de emergência, simulação da meta de R$ 300k e renda passiva.
6. **Backend & Persistência Local/Prisma**: Node.js + Express API + PostgreSQL.
7. **PWA & Offline First**: Service worker, web manifest, suporte a instalação em desktop e mobile.
8. **Integrações de Dados Reais**: Provedores de cotações em dólar, câmbio USD/BRL e feed RSS de notícias financeiras.
9. **Deploy em Nuvem**: Configuração para Vercel/Railway/Fly.io, variáveis de ambiente seguras e HTTPS.
